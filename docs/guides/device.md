# 简单教程：刷机和使用设备

准备 AI Passport（ESP32-C3、8 MB Flash）、一条能传数据的 USB 线，以及电脑上的 Chrome 或 Edge。刷机使用电脑；配网可以用手机。

## 1. 下载固件

打开 [PocketLink Releases](https://github.com/androidmumo/pocketlink/releases)，在需要的版本下展开 **Assets**，下载 **`pocketlink-full.bin`**。这是完整刷机包，不需要安装开发环境。

第一次安装走下面的 USB 刷机步骤。已经装好 PocketLink、只想升级？跳到[在线升级](#在线升级)。刷机前如设备有重要配置，先按[技术说明](../development/device-provisioning.md#构建与刷机)备份；更换玩法后原应用的设置可能不再适用。

## 2. 用官方网页刷机

1. 用 USB 数据线连接设备和电脑，关闭占用设备串口的其他软件。
2. 用电脑 Chrome 或 Edge 打开[官方刷机页面](https://ai-passport.folotoy.cn/tools/web-flasher/)。
3. 选择 **“安装本地固件”**，点击 **“连接设备”**，在浏览器弹窗中选择对应串口。
4. 点击 **“选择 .bin 文件”**，选择刚下载的 `pocketlink-full.bin`，核对写入地址为 **`0x0`**。只添加这一个文件。
5. 点击 **“开始写入”**，保持 USB 连接，等页面提示完成，再按页面提示重启；必要时断电重新连接。
6. 屏幕出现 PocketLink 或配网二维码，即可继续。

**不要点击“清除设备数据”，也不要执行整片擦除。** 完整包不包含设备身份区；官方页面当前写入流程不执行整片擦除。若页面提示文件不兼容，先停下核对文件，不能用擦除解决。看不到串口时，先换数据线/USB 接口，再参考[官方教程](https://ai-passport.folotoy.cn/guides/)。

## 3. 给设备配网

1. 先打开你要使用的 PocketLink 服务网页。没有账号时，让管理员提供**注册邀请码**后注册；管理员在登录页选择“管理员”。
2. 在“我的设备”中填写名称，生成**设备配对码**。它与注册邀请码、房间邀请码不同，10 分钟内有效。
3. 扫描设备屏幕二维码，连接设备热点。手机提示热点不能上网时，选择继续连接。
4. 在手机浏览器打开 **`http://192.168.4.1`**，填写家中 Wi-Fi 名称/密码、服务端地址/端口和配对码。
5. 服务端地址填写域名，例如 `pocketlink.example.com`，HTTPS 端口一般为 **443**，不是 Docker 内部映射的 3002。
6. 保存后等待设备联网。回到服务网页刷新设备列表，确认设备已添加。手机可切回原 Wi-Fi。

已有网络时长按确定键进入配网，再长按确定键可取消并恢复原网络。Wi-Fi 密码和配对码不要发到聊天或公开页面。

## 4. 收消息和对讲

在网页“房间与消息”顶部点击“创建房间”，并在“接收设备”勾选自己的设备。随后发送文字，设备会收到消息。朋友可注册后通过“加入房间”输入你生成的**房间邀请码**。

| 在设备上 | 操作 |
| --- | --- |
| 消息翻页 | 短按上 / 下键 |
| 标记已读，继续接收 | 短按确定键 |
| 进入 / 取消配网 | 收信页长按确定键 |
| 检查更新 | 收信页长按上键 |
| 进入对讲 | 收信页长按下键 |
| 切换对讲房间 | 对讲页短按上 / 下键 |
| 讲话 / 收听 | 对讲页按住确定 / 松开确定 |
| 退出对讲 | 对讲页长按下键 |

网页参与对讲：选择房间 →“连接对讲”→ 允许麦克风 → 按住“按住讲话”。同一房间一次只能一人讲话。设备对讲期间暂停收信，退出后继续接收。测试时将两个发声设备拉开距离，避免啸叫。

## 在线升级

管理员先在网页“固件管理”上传同一 Release 的 `manifest.json` 和 `pocketlink-ota.bin`，点击发布。官方维护的服务若已发布，则无需重复上传。

设备联网并接上稳定电源，在收信页**长按上键**检查版本，确认后**长按下键**安装，等待自动重启。不是自动强制升级。不要把 `pocketlink-full.bin` 上传到 OTA 管理页。

当前 0.5.0 的真机安装、音质和延迟仍待验收。升级前保留的旧消息可能没有发送人/时间；用新消息检查即可。
