# 房间对讲（P4 开发版）

首版为半双工 PTT：同一房间同一时刻只能一人讲话，按住讲话、松开收听。支持设备与设备、网页与设备、网页与网页。语音仅实时转发，不写入 SQLite，也不提供离线语音或录音回放。文字仍独立持久化。

## 使用

1. 管理员发放注册邀请码，用户注册并登录；注册邀请只在管理员的“注册邀请码”页面管理。
2. 在“房间与消息”顶部操作区创建房间、加入房间或邀请朋友。房间邀请码仅在当前房间的“邀请朋友”面板生成、查看、复制及撤销，不能用于注册。
3. 在“接收设备”勾选自己的设备。设备只能进入已勾选且账号有权访问的有效房间；移除设备/用户、归档房间或撤销设备凭证后，对讲连接会在约一秒内关闭。
4. 设备在收信页长按下键进入对讲；上下键短按切换房间，按住确定键讲话，松开收听，长按下键退出。正在对讲时暂停设备文字轮询和 OTA 检查，退出后继续接收积压文字。配网与升级保留在收信页。
5. 网页选择房间，点击“连接对讲”，授权麦克风。连接后按住“按住讲话”按钮，也支持聚焦按钮后按空格或 Enter；松开停止。退出、换房、切换页面或切到后台会释放麦克风/连接，返回后需重新连接。
6. 单次讲话客户端最多 29 秒，服务端麦权最多 30 秒。抢麦失败、申请超时或达到时限后，必须松开再按，不自动排队或在稍后突然开麦。

网页需要 HTTPS、WebSocket、麦克风和 AudioWorklet 支持。拒绝麦克风权限时会提示，可授权后重试。首次测试请把手机/电脑与设备保持距离，避免扬声器声音被另一端麦克风再次采集。设备默认音量 55%。手机页面按产品要求禁止缩放；仍需实际手机浏览器验收。

## 消息与时间

设备消息顶部显示服务器提供的 `sender`（账号名）和 `created_at`（发送时间），不使用设备接收时刻代替发送时间。右上角显示当前 `HH:mm`，SNTP 校时，固定北京时间 UTC+8，未校时显示 `--:--`。消息发送时间显示到分钟。增加元数据后正文每页六行，仍以翻页方式阅读。

原 `state` NVS blob 结构保持不变，消息元数据另存 `inbox_meta` 并核对消息 ID，升级不清除 Wi-Fi、凭证、收信或身份区。升级前已保存在设备的旧消息没有元数据，会显示未知；新收到的消息具有发送人与时间。校时仅为设备时钟，不改变服务器保存的 UTC 时间。

## 接口与帧

- `GET /api/v1/device/rooms`：Bearer 设备凭证，返回已加入且有效的房间。
- `WSS /api/v1/device/voice/{room_id}`：Bearer 设备凭证，无浏览器 Origin。
- `WSS /api/v1/voice/{room_id}`：网页会话 Cookie，Origin 必须精确匹配配置值。
- 必须协商子协议 `pocketlink.voice.v1`，不接受查询字符串中的凭证或其他参数。

控制帧是有界 JSON：客户端发送 `{"type":"request","request_id":1}`；服务端返回 `grant` 或 `busy`（包含对应 `request_id`）。授权包含 `stream` 和 `lease_ms`；房间成员收到 `{"type":"floor","stream":1,"sender":"账号或设备名"}`。松手发送 `{"type":"release","stream":1}`；空闲 floor 的 stream 为 0。提前松手后的迟到授权立即释放，不能触发录音。

每个二进制帧恰好 648 字节：0–3 是大端 uint32 流代次，4–7 是大端 uint32 序号（从 1 开始），8–647 是 320 个小端有符号 16 位 PCM 样本。16 kHz、单声道、20 ms 一帧，单向音频约 256 kbit/s，不含传输开销。服务端检查当前持有人、代次、序号和速率，不相信客户端声明的发送人。

最多 32 个语音连接，网页每个登录会话一个、设备每台一个；与文字流共用 64 个连接的全局上限。每个连接发送队列最多 16 帧，设备接收与网页采集待处理队列最多 8 帧；服务端/设备对超过 160ms 的本地音频队列帧丢弃，发送积压则断开。每秒最多 60 帧音频、10 个控制请求。权限和会话每秒复查，静默连接使用 WebSocket ping/pong 保活。

首版使用现有 HTTPS/WSS 端口和 1Panel 代理，不新增公网端口。WSS 使用 TCP，弱网仍可能出现队头阻塞和延迟；本版没有 DTLS/UDP、Opus/ADPCM、音频持久化、端到端加密或服务器混音。这些不应标记为已完成。

## 验证与依赖

主机测试覆盖麦权争抢、非持有人拒绝、跨房间隔离、重放、到期、慢客户端、握手边界、权限撤销、浏览器 44.1/48 kHz 转换及有限采集队列。设备 PTT 状态机独立测试提前松手、迟到授权、超时和要求重新按下。

`tests/console/voice-browser.cjs` 仅接受回环 HTTPS 测试服务，使用模拟麦克风和模拟设备验证双向 PCM、抢麦、松手与页面离开清理。使用与 `tests/console/browser.cjs` 相同的 `POCKETLINK_PLAYWRIGHT`、`POCKETLINK_TEST_PASSWORD_FILE` 环境变量；测试代理必须支持 WebSocket Upgrade。

固件使用固定的 [Espressif esp_websocket_client 1.6.1](https://components.espressif.com/components/espressif/esp_websocket_client/versions/1.6.1/readme)，启用证书包验证。LVGL 保持 9.5.0。构建和模拟音频不能代替麦克风/扬声器音质、延迟、真实手机兼容性、两台设备抢麦、断网恢复和运行内存峰值的真机验收。
