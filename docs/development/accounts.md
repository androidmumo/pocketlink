# 邀请注册与共享房间

## 使用方式

1. 管理员在登录页选择“管理员”，使用原来的服务器密码文件登录。没有默认密码，注册不能获得管理员权限。
2. 打开“邀请码”，生成注册邀请码并私下交给对方。完整邀请码仅生成时显示，可复制；有效期 7 天，限一人使用，可在使用前撤销。
3. 对方选择“邀请码注册”，填写用户名、密码和邀请码。成功后回到登录页，用新账号登录。
4. 用户在“我的设备”生成设备配对码，设备绑定到生成该码的账号。设备配对码有效期仍为 10 分钟，与注册邀请码不同。
5. 房主在“房间与消息”创建房间，在“房间伙伴”点击“邀请”。朋友登录后在“加入朋友的房间”输入房间邀请码，接受邀请。
6. 每个人自行勾选自己的设备作为接收设备。加入前的历史消息不向新用户开放；新设备不补收加入前的消息。
7. 房主可移除伙伴，伙伴可退出；对应设备从该房间移除，尚未投递的消息停止投递。已经显示在离线设备上的文字不能即时擦除。

用户名统一转为小写，3–32 位、字母开头，仅字母、数字和下划线；`admin` 保留。密码至少 12 个字符，最多 128 个 UTF-8 字节，不自动去除首尾空格。暂无邮箱验证、找回密码、账号改名或账号删除功能，请保存好密码。

## 权限

| 操作 | 管理员 | 普通用户 / 房间伙伴 |
| --- | --- | --- |
| 注册邀请码 | 生成、查看自己生成的记录、撤销 | 不可生成 |
| 设备 | 维护全部设备 | 仅自己的设备 |
| 房间 | 维护全部房间 | 创建自己的房间，访问自己创建或已接受邀请的房间 |
| 房间邀请、归档、移除伙伴 | 可操作全部房间 | 仅房主；伙伴可退出 |
| 添加接收设备 | 可维护全部设备 | 只能自行添加自己的设备 |
| 消息及回执 | 查看全部房间 | 可访问房间内加入后的消息与回执 |
| 固件包与发布通道 | 可上传、发布、撤回、删除 | 无权限；设备仍按自身凭证下载公开发布的签名升级 |

管理员有全局管理权限，账号隔离不等于对管理员端到端加密。设备 SN 是标识，不能代替密钥。
即使原设备已撤销，也不能用另一账号的配对码接管同一 SN；本版不提供跨账号转移设备功能。

## API

所有浏览器写请求沿用精确 Origin、Secure/HttpOnly/SameSite=Strict Cookie 和无 CORS 的规则。

| 方法及路径 | 输入 / 结果 |
| --- | --- |
| `POST /api/v1/auth/login` | `{username,password}`；`admin` 使用文件密码；省略用户名保留旧管理员 API 兼容性 |
| `POST /api/v1/auth/register` | `{username,password,code}`；消费注册邀请码，创建账号；成功后需登录 |
| `GET /api/v1/auth/me` | `{authenticated,user:{id,username,created_at},role}` |
| `GET /api/v1/invitations` | 自己生成的邀请码元数据，不返回邀请码或摘要 |
| `POST /api/v1/invitations` | `{kind:"registration"}` 或 `{kind:"room",room_id}`；返回一次性的 `{id,code,expires_at}` |
| `DELETE /api/v1/invitations/{id}` | 撤销自己生成的邀请码 |
| `POST /api/v1/rooms/join` | `{code}`；接受房间邀请，返回 `{room_id}` |
| `GET /api/v1/rooms/{id}/users` | 房主与房间伙伴 |
| `DELETE /api/v1/rooms/{id}/users/{user_id}` | 房主移除伙伴或本人退出，同时撤回对应设备投递 |

设备、房间和消息接口路径保持不变，但服务端按登录账号检查权限，不接受客户端传入的角色或归属。
房间历史保存加入时的消息 ID 边界，避免同秒加入导致旧消息泄露；回执和幂等重试也检查该边界。

## 存储、限制与升级

迁移 `005_accounts.sql` 新增账号、邀请码、房间用户及设备/配对码/房间归属，已有数据归 `admin`，原设备凭证、消息和回执保留。账号密码使用独立随机盐及 600,000 次 PBKDF2-HMAC-SHA256；邀请码含 256 位随机数，数据库只存 SHA-256 摘要，消费与创建账号或加入房间在同一事务完成。

最多 256 个账号（含管理员）、1024 条未过期邀请记录、256 个浏览器会话且单账号最多 16 个会话；会话 12 小时有效，服务重启后失效。创建邀请时清理过期邀请记录，因此此列表不是长期审计日志。账号登录、注册与设备配对共享每分钟 20 次限额，密码计算最多一个并发；消息相关写请求沿用全局每分钟 120 次限制。其他设备/房间/消息总量限制不变。

升级前必须备份数据库及部署配置。迁移成功后旧镜像不能打开新结构，回退需要恢复匹配的升级前数据库，会丢失备份后的写入。管理员密码仍从原文件读取，不写入账号表或 Git。

## 验证

主机测试覆盖旧库迁移、跨账号访问拒绝、邀请过期/撤销/并发单次使用、重新打开数据库、加入前历史隔离、移除成员后停止投递、设备 SN 归属及管理员固件权限。真实浏览器脚本为 `tests/console/browser.cjs`，仅允许回环 HTTPS 临时服务；覆盖注册登录、配对、房间发信/回执及桌面和手机布局，不使用生产数据。
